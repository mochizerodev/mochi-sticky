Goal: Make Boards kanban usable across terminal sizes.

Scope:
- Implement breakpoints and resize guarantees from the board description.
- Kanban: 3 columns when they fit; 2-column viewport when tight; 1-column focus when very tight.
- Preserve selection and active column on resize.

Implemented (2026-02-17):
- Added responsive kanban degradation in Boards tasks view: shows 3, 2, or 1 visible columns based on available panel width.
- Added horizontal viewport behavior for tight widths: h/l changes active column and the viewport follows so the active column remains visible.
- Added auto list fallback for very narrow task panes (below width 70) while preserving task selection.
- Added manual override toggle with uppercase L: list <-> kanban; in narrow mode this allows forcing kanban even when auto-list would apply.
- Added list-view keyboard behavior so j/k walks tasks across all columns while keeping existing task actions and enter-to-open behavior.

Acceptance:
- Resizing the terminal never loses the selected task.
- Kanban degrades gracefully (3->2->1 columns) before forcing list view.
