Goal: Allow deleting a wiki page directly from the TUI so users don't need to switch to the CLI.

Scope:
- Add a delete action in the wiki page view/list flows (e.g., keybinding or actions menu).
- Show a clear confirmation prompt (page title + slug) and require explicit confirmation.
- After delete, refresh the wiki list/index in the TUI so the removed page disappears immediately.
- Respect storage root overrides and mirror CLI behavior (including any index updates required by the wiki subsystem).

Acceptance:
- From the TUI, I can delete an existing wiki page and see it removed from the list.
- Canceling the confirmation leaves the page untouched.
- Deleting a non-existent page surfaces a readable error (no panic).
- Basic coverage exists (integration or unit test) for the delete flow.
