Goal: Create a new board directly from a task so users can quickly split large work items into dedicated planning spaces.

Scope:
- Add a flow to create a board from a selected task with sensible defaults (board name from task title and initial metadata).
- Optionally migrate the source task into the newly created board or leave a linked reference based on user choice.
- Surface the new board in board listings and update task details with cross-links for traceability.

Acceptance:
- Users can trigger "create board from task" from CLI/TUI/MCP and receive the new board identifier/name.
- New board creation handles naming conflicts and reports deterministic behavior.
- Source task and new board keep clear linkage so users can navigate between them after creation.
