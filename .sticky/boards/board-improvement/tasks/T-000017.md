Goal: Allow tasks to move between boards without losing metadata so teams can reorganize work safely as priorities change.

Scope:
- Add command/API support to move a task to a target board while preserving ID, status, priority, tags, dependencies, and content.
- Handle edge cases such as active board changes, missing destination boards, and dependency references that span boards.
- Update TUI/CLI feedback to confirm source/destination and show clear errors when moves are blocked.

Acceptance:
- A user can move any existing task from one board to another using CLI/TUI/MCP pathways.
- Moved tasks keep full history/metadata and appear in destination listings immediately.
- Tests cover successful moves, invalid destination board handling, and dependency integrity checks.
